# 19. XÁC NHẬN IN_GAME

Không xác nhận ngay khi signal vừa biến mất.

Phải đảm bảo:

```text
Signal 1 absent
AND
Signal 2 absent
AND
Signal 3 absent
```

liên tục:

`>= 3 giây`

mới chuyển:

`IN_GAME`

Nếu trong 3 giây bất kỳ signal nào quay lại:

reset timer.

Pseudo logic:

```python
if any_signal_detected:
    absent_since = None

else:
    if absent_since is None:
        absent_since = now

    if now - absent_since >= 3:
        state = IN_GAME
```

# 28. BOSS LOOP

Flow:

```python
while not stop_event.is_set():

    ensure_in_game()

    enter_boss(selected_boss)

    interruptible_wait(3)

    dead_streak = 0

    while not stop_event.is_set():

        text = read_boss_hp()

        if contains_digit(text):
            dead_streak = 0

        else:
            dead_streak += 1

            if dead_streak >= 2:
                break

        interruptible_wait(2)

    if stop_event.is_set():
        break

    exit_boss()

    interruptible_wait(16)
```

Sau 16 giây:

không được assume vẫn IN_GAME.

Phải quay lại:

`ensure_in_game()`

rồi mới Enter Boss tiếp.

# 30. STOP

Stop phải hoạt động trong mọi state.

Ví dụ:

* copying nếu implementation hỗ trợ cancel an toàn;
* startup wait 10s;
* waiting game;
* confirming 3s;
* entering Boss;
* wait Boss 3s;
* OCR loop;
* wait OCR 2s;
* wait respawn 16s.

Không dùng sleep dài kiểu:

```python
time.sleep(16)
```

nếu nó khiến Stop phải đợi.

Implement helper tương đương:

```python
def interruptible_wait(seconds, stop_event):
    return stop_event.wait(seconds)
```

Nếu trả về True:

Stop đã được yêu cầu.

Khi Stop:

* không click thêm;
* không OCR thêm;
* không Enter Boss thêm;
* không Exit Boss thêm trừ khi source bắt buộc cleanup an toàn;
* không restart game;
* worker thoát sạch.
